## Getting Started

As a software engineer you will spend a significant amount of time reading and understanding code that 
already exists. Whether you're debugging a production issue, understanding how a feature works, or 
integrating new code into a large system, you will need to quickly find what you are looking for in the 
codebase. This repo and set of exercises will give you experience with the `grep` and `find` tools.

## Challenge

1. Clone this project onto your local machine and use your preferred Terminal to preform the following tasks. Store your answers in a word document and include a screen shot of each answer.

2. Use the find command to identify how many java files are in this project. 

3. Next, use the command from above and pipe the result into the word count `wc` to determine how many java files there are
